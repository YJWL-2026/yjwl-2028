## 1. 方案说明

### 接入方案：WebView内嵌 + 原生登录页

```
微信小程序
├── 原生登录页（输入账号密码 → 获取Token）
│     │
│     ▼ Token保存在本地
│     │
├── 首页（web-view组件）
│     │
│     ▼ 通过URL参数传递Token: https://域名/dashboard?token=xxx
│     │
└── WebView内嵌现有Web系统
        │
        ├── 教师功能（场景编辑器、灾害查询、企业大屏...）
        └── 学生功能（决策推演、素养画像...）
```

**优势**：
- 前端几乎不用改，现有Web页面直接嵌入
- 后端只需增加一个Token接口
- 登录页用原生开发，体验好
- 上线快（1-2天）

## 2. 注册微信小程序账号

### 2.1 访问微信公众平台

打开浏览器访问：**https://mp.weixin.qq.com**

点击右上角"立即注册"

### 2.2 选择账号类型

选择"小程序"

### 2.3 填写邮箱和密码

- 使用一个未注册过微信公众平台/个人微信的邮箱
- 设置密码并确认

### 2.4 邮箱激活

登录邮箱，点击激活链接

### 2.5 选择主体类型

| 类型 | 适用 | 需要材料 |
|------|------|---------|
| 个人 | 个人开发者/教师 | 身份证 |
| 企业 | 学校/公司 | 营业执照/组织机构代码 |

> 💡 **教学场景建议**：个人类型即可，免费且快速。企业类型可发布到线上让所有人搜索到。

### 2.6 完善信息

填写小程序名称（如"应急决策教学系统"）、简介、头像等

### 2.7 获取AppID

注册完成后，在"开发" → "开发管理" → "开发设置"中找到 **AppID**

```
AppID(小程序ID): wx1234567890abcdef
```

**记录这个AppID，后面要用。**

## 4. 导入小程序项目

### 4.1 导入项目

打开微信开发者工具：
1. 点击"+"号或"导入项目"
2. 项目目录选择：`miniprogram` 文件夹（项目根目录下的 miniprogram/）
3. AppID：填入您在第2步获取的AppID
4. 项目名称：应急决策教学系统
5. 点击"导入"

### 4.2 项目结构

```
miniprogram/
├── app.js              # 小程序入口（配置服务器地址）
├── app.json            # 全局配置
├── app.wxss            # 全局样式
├── project.config.json # 项目配置
├── sitemap.json
└── pages/
    ├── index/          # 首页（WebView内嵌）
    │   ├── index.wxml
    │   ├── index.js
    │   ├── index.json
    │   └── index.wxss
    └── login/          # 原生登录页
        ├── login.wxml
        ├── login.js
        ├── login.json
        └── login.wxss
```

### 4.3 修改AppID

打开 `project.config.json`，将 `your-appid-here` 替换为您的AppID：

```json
{
  "appid": "wx1234567890abcdef",
  ...
}
```

## 5. 配置服务器地址

### 5.1 修改小程序配置

打开 `app.js`，修改 `apiBase` 和 `webUrl`：

```javascript
App({
  globalData: {
    // 开发环境：本地地址
    apiBase: 'http://127.0.0.1:5000',

    // 生产环境：您的HTTPS域名
    // apiBase: 'https://your-domain.com',

    webUrl: 'http://127.0.0.1:5000/login',
    ...
  }
})
```

**本地开发时**：使用 `http://127.0.0.1:5000`

**正式发布时**：必须使用 `https://您的域名`

### 5.2 关闭URL域名校验（本地开发）

在开发者工具中：
1. 点击右上角"详情"
2. "本地设置"
3. 勾选"不校验合法域名、web-view（业务域名）、TLS版本以及HTTPS证书"

这样开发时可以用 `http://127.0.0.1:5000` 调试。

## 7. 配置业务域名

> 正式发布前必须完成此步骤。本地开发可跳过。

### 7.1 准备HTTPS域名

1. 购买域名（阿里云/腾讯云，约8-50元/年）
2. 域名备案（国内服务器必须备案，约7-15个工作日）
3. 部署系统到云服务器（参考`docs/部署教程.md`）
4. 配置HTTPS证书（Let's Encrypt免费证书）

### 7.2 在小程序后台配置

1. 登录 https://mp.weixin.qq.com
2. "开发" → "开发管理" → "开发设置"
3. "服务器域名" → "修改"
4. 添加以下域名：

| 类型 | 域名 |
|------|------|
| request合法域名 | `https://your-domain.com` |
| web-view业务域名 | `https://your-domain.com` |

> ⚠️ **注意**：业务域名需要下载校验文件，上传到服务器根目录。

### 7.3 业务域名校验文件

在小程序后台下载校验文件（如 `xxx.txt`），将其放到Web服务器的根目录，使 `https://your-domain.com/xxx.txt` 可访问。

Nginx配置（已内置在 `deploy/nginx.conf` 中）会自动处理。

2. 填写版本号（如 1.0.0）和备注

1. 登录 https://mp.weixin.qq.com
2. "管理" → "版本管理"
3. 找到刚上传的版本 → "提交审核"

1. 在版本管理页面找到审核通过的版本

1. "管理" → "版本管理" → "体验版"

## 10. 后端Token认证说明

### 10.1 Token认证流程

```
小程序登录页
    │
    │ POST /api/auth/token
    │ {username, password}
    ▼
Flask后端验证账号密码
    │
    │ 生成Token (SHA256)
    │ 存入内存 _TOKEN_STORE
    ▼
返回 {token, user, expires_in}
    │
    │ Token保存到本地存储
    ▼
后续所有请求携带 Token
    │
    ├── wx.request → Authorization: Bearer <token>
    └── web-view URL → ?token=<token>
```

### 10.2 API接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/auth/token` | POST | 账号密码登录，返回Token |
| `/api/session` | GET | 检查登录状态（支持Token） |
| `/api/logout` | POST | 退出登录（清除Token） |
| 其他所有API | - | 支持 `Authorization: Bearer <token>` 请求头 |

### 10.3 Token有效期

- 默认 **7天**
- Token存储在服务器内存中（重启服务后失效，需重新登录）
- 每次请求自动检查过期，过期自动清除

### 10.4 兼容性

后端同时支持两种认证方式：
1. **Cookie/Session**（Web浏览器自动携带）
2. **Token**（小程序通过请求头或URL参数携带）

两种方式互不干扰，Web端和小程序端可同时使用。

## 11. 常见问题

### Q1: 模拟器中登录后白屏

**原因**：服务器未启动或地址配置错误。

**解决**：
1. 确认Flask服务器正在运行（`http://127.0.0.1:5000`）
2. 检查 `app.js` 中 `apiBase` 地址正确
3. 开发者工具中勾选"不校验合法域名"

### Q2: web-view显示空白

**原因**：业务域名未配置或非HTTPS。

**解决**：
- 开发环境：勾选"不校验合法域名"
- 生产环境：在后台配置业务域名（必须HTTPS）

### Q3: 登录提示"网络错误"

**原因**：服务器地址不对或CORS未配置。

**解决**：
1. 检查 `app.js` 中 `apiBase` 是否正确
2. 确认服务器在运行
3. 检查服务器防火墙/安全组是否放行端口

### Q4: Token过期后需要重新登录

**原因**：Token有效期7天。

**解决**：这是正常行为。如需延长，修改 `app.py` 中 `_TOKEN_EXPIRE_SECONDS`。

### Q5: 发布后地图不显示

**原因**：高德地图瓦片源在小程序web-view中可能受限。

**解决**：确保服务器能正常访问外网，或考虑在原生小程序中使用微信地图组件。

### Q6: 小程序包体积超限

**原因**：小程序主包限制2MB。

**解决**：WebView方案主包很小（约几十KB），不会超限。如果有图片资源，放到服务器上用URL引用。

### Q7: 审核被拒

**常见原因**：
- 小程序涉及医疗/金融等特殊行业（本系统不属于）
- 功能不完整（确保所有页面可用）
- 需要企业资质（个人小程序功能有限制）

**解决**：按审核意见修改后重新提交。
