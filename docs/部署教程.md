## 1. 部署架构概览

```
手机/电脑浏览器
       │
       ▼ (HTTP/HTTPS)
   公网IP / 域名
       │
       ▼
┌──────────────────────────┐
│      Nginx (端口80/443)   │  ← 反向代理 + 静态文件加速
│                          │
│  ┌────────────────────┐  │
│  │ Gunicorn (端口5000) │  │  ← 生产级WSGI服务器，4个worker
│  │                    │  │
│  │  Flask Application │  │  ← 应急决策教学系统
│  │  ├─ 决策引擎        │  │
│  │  ├─ 实时灾害API     │  │
│  │  ├─ 登录系统        │  │
│  │  └─ 场景管理        │  │
│  └────────────────────┘  │
│                          │
│  场景文件 (scenarios/)   │
│  静态资源 (static/)      │
└──────────────────────────┘
```

**技术栈**：Nginx（反向代理）+ Gunicorn（WSGI服务器）+ Flask（应用）+ Systemd（进程管理）

## 2. 购买云服务器

### 2.1 推荐云服务商

| 服务商 | 推荐产品 | 价格 | 适用场景 |
|--------|---------|------|---------|
| 阿里云 | 轻量应用服务器 | 24元/月起 | 新手友好，控制台简单 |
| 腾讯云 | 轻量应用服务器 | 25元/月起 | 性价比高，带宽充足 |
| 华为云 | Flexus云服务器 | 29元/月起 | 教育优惠多 |

### 2.2 配置选择

| 配置项 | 最低配置 | 推荐配置 |
|--------|---------|---------|
| CPU | 1核 | 2核 |
| 内存 | 1GB | 2GB |
| 系统盘 | 40GB SSD | 50GB SSD |
| 带宽 | 3Mbps | 5Mbps |
| 系统 | Ubuntu 22.04 LTS | Ubuntu 22.04 LTS |

> 💡 **教学场景建议**：一个班级30-50人同时访问，2核2G + 5Mbps带宽足够。

### 2.3 购买步骤（以阿里云为例）

1. 访问 https://www.aliyun.com → 登录账号
2. 搜索"轻量应用服务器" → 点击购买
3. 选择配置：
   - 地域：选离您最近的（如华东1-杭州）
   - 镜像：**Ubuntu 22.04 LTS 64位**
   - 套餐：2核2G / 5Mbps
   - 购买时长：按需（1年起更优惠）
4. 设置服务器密码（记好！后面要用）
5. 确认订单并支付

购买完成后，在控制台找到服务器的 **公网IP地址**（形如 `47.96.xxx.xxx`）。

## 3. 连接服务器

### 3.1 Windows 用户

**方法一：使用 PowerShell（推荐）**

按 `Win + X` → 选择"终端"或"PowerShell"，输入：

```bash
ssh root@你的服务器IP
```

输入密码（购买时设置的），首次连接输入 `yes` 确认。

**方法二：使用 PuTTY**

1. 下载 PuTTY：https://www.putty.org/
2. Host Name：输入服务器IP
3. Port：22
4. 点击 Open → 输入用户名 `root` → 输入密码

### 3.2 Mac 用户

打开"终端"应用：

```bash
ssh root@你的服务器IP
```

### 3.3 验证连接成功

连接后看到类似以下提示即成功：

```
root@hostname:~#
```

## 4. 上传项目代码

### 4.1 打包项目（在本地电脑执行）

在项目根目录（`2026-07-21-10-09-28` 文件夹）下，将以下文件/文件夹打包为 zip：

**必须上传的内容：**

```
emergency-decision/
├── src/
│   └── emergency_decision/    # 核心代码
│       ├── api/
│       ├── web/
│       ├── engine/
│       ├── data/
│       ├── models.py
│       ├── realtime_data.py
│       └── ...
├── scenarios/                  # 场景文件
├── requirements.txt            # Python依赖
├── wsgi.py                     # WSGI入口
└── deploy/                     # 部署配置
    ├── deploy.sh
    ├── nginx.conf
    └── emergency-decision.service
```

**Windows 打包命令**（PowerShell）：

```powershell
cd C:\Users\HW\WorkBuddy\2026-07-21-10-09-28
# 用 7-Zip 或资源管理器手动打包上述文件夹为 emergency-decision.zip
```

### 4.2 上传到服务器

**方法一：使用 scp（命令行）**

```bash
scp -r ./emergency-decision root@你的服务器IP:/opt/
```

**方法二：使用 WinSCP（图形界面，推荐新手）**

1. 下载 WinSCP：https://winscp.net/
2. 协议：SCP → 主机名：服务器IP → 用户名：root → 密码
3. 左侧选中本地 `emergency-decision` 文件夹
4. 右侧导航到 `/opt/` 目录
5. 拖拽上传

**方法三：使用宝塔面板（最简单）**

1. 在服务器上安装宝塔面板：
   ```bash
   curl -sSO https://download.bt.cn/install/install_panel.sh && bash install_panel.sh
   ```
2. 访问宝塔面板 → 文件管理 → 上传

### 4.3 验证文件

上传完成后，在服务器上执行：

```bash
ls /opt/emergency-decision/
```

应能看到 `src`、`scenarios`、`requirements.txt`、`wsgi.py`、`deploy` 等内容。

## 5. 一键部署

### 5.1 执行部署脚本

```bash
cd /opt/emergency-decision
bash deploy/deploy.sh
```

脚本会自动完成：
1. ✅ 安装 Python3、Nginx 等系统依赖
2. ✅ 创建 Python 虚拟环境
3. ✅ 安装 Flask、Gunicorn 等依赖
4. ✅ 配置 Systemd 服务（开机自启）
5. ✅ 配置 Nginx 反向代理
6. ✅ 启动服务并检查状态

### 5.2 部署成功标志

看到以下输出即部署成功：

```
==========================================
  部署完成！
==========================================

  访问地址:  http://47.96.xxx.xxx
  手机访问:  用手机浏览器打开上面的地址

  管理命令:
    查看状态:  systemctl status emergency-decision
    重启服务:  systemctl restart emergency-decision
    查看日志:  journalctl -u emergency-decision -f

  虚拟账号:
    教师: teacher01 / teach123
    学生: student01 / stud123
```

### 5.3 如果部署失败

查看详细错误日志：

```bash
# 查看Flask应用日志
journalctl -u emergency-decision -n 50 --no-pager

# 查看Nginx错误日志
tail -20 /var/log/nginx/error.log
```

## 6. 配置安全组/防火墙

### 6.1 阿里云轻量服务器

1. 进入控制台 → 找到您的服务器实例
2. 点击"防火墙" → "添加规则"
3. 添加以下规则：

| 应用类型 | 协议 | 端口范围 | 说明 |
|---------|------|---------|------|
| HTTP | TCP | 80 | Web访问 |
| HTTPS | TCP | 443 | HTTPS访问（可选）|
| SSH | TCP | 22 | 远程连接（默认已开）|

### 6.2 腾讯云轻量服务器

1. 控制台 → 轻量应用服务器 → 点击实例
2. "防火墙" → "添加规则"
3. 同上添加 80 和 443 端口

### 6.3 服务器内部防火墙（一般已自动配置）

如果仍无法访问，检查 UFW：

```bash
ufw allow 80/tcp
ufw allow 443/tcp
ufw status
```

## 8. 绑定域名（可选）

### 8.1 购买域名

1. 阿里云/腾讯云购买域名（约 8-50元/年）
2. 实名认证（必须，约1个工作日）

### 8.2 域名解析

在域名管理控制台添加 A 记录：

| 记录类型 | 主机记录 | 记录值 | TTL |
|---------|---------|--------|-----|
| A | @ | 你的服务器公网IP | 600 |
| A | www | 你的服务器公网IP | 600 |

等待 5-10 分钟解析生效。

### 8.3 修改 Nginx 配置

```bash
nano /etc/nginx/sites-available/emergency-decision
```

将 `server_name _;` 改为你的域名：

```nginx
server_name your-domain.com www.your-domain.com;
```

保存后重启 Nginx：

```bash
systemctl restart nginx
```

## 9. 配置HTTPS（可选但推荐）

> 手机端如果用域名访问，建议配置 HTTPS，部分手机浏览器对 HTTP 有限制。

### 9.1 安装 Let's Encrypt 证书（免费）

```bash
# 安装 Certbot
apt install -y certbot python3-certbot-nginx

# 申请证书（按提示操作）
certbot --nginx -d your-domain.com -d www.your-domain.com

# 自动修改Nginx配置并重启
```

### 9.2 自动续期

Let's Encrypt 证书有效期 90 天，Certbot 会自动设置续期：

```bash
# 测试自动续期
certbot renew --dry-run
```

## 10. 日常运维命令

### 10.1 服务管理

```bash
# 查看服务状态
systemctl status emergency-decision

# 重启Flask应用
systemctl restart emergency-decision

# 停止服务
systemctl stop emergency-decision

# 查看实时日志（排错用）
journalctl -u emergency-decision -f

# 重启Nginx
systemctl restart nginx
```

### 10.2 更新代码

当本地修改了代码后，重新上传到服务器，然后：

```bash
cd /opt/emergency-decision
systemctl restart emergency-decision
```

### 10.3 查看访问日志

```bash
# Nginx访问日志
tail -50 /var/log/nginx/access.log

# 按IP统计访问量
awk '{print $1}' /var/log/nginx/access.log | sort | uniq -c | sort -rn | head -20
```

## 11. 常见问题排查

### Q1: 访问IP显示白屏/连接超时

**排查步骤：**

```bash
# 1. 检查Flask是否在运行
systemctl status emergency-decision

# 2. 检查Nginx是否在运行
systemctl status nginx

# 3. 检查端口是否在监听
ss -tlnp | grep -E '80|5000'

# 4. 检查防火墙/安全组是否放行80端口
# (在云控制台检查安全组规则)
```

### Q2: 页面能打开但地图不显示

**原因**：地图瓦片源（高德地图）被限速或网络问题。

**解决**：等待几秒自动重试，或检查服务器是否能访问外网：

```bash
curl -I https://webrd0{1-4}.is.autonavi.com/appmaptile 2>&1 | head -5
```

### Q3: 登录后页面空白

```bash
# 查看错误日志
journalctl -u emergency-decision -n 30 --no-pager

# 常见原因：scenarios 目录权限不足
chown -R www-data:www-data /opt/emergency-decision/scenarios/
chmod -R 755 /opt/emergency-decision/scenarios/
systemctl restart emergency-decision
```

### Q4: 灾害数据不显示

**原因**：服务器无法访问地震台网/天气预警API。

**解决**：

```bash
# 测试外网连通性
curl -s https://www.wolfx.jp/api/earthquake | head -c 200
```

如果无法访问，检查服务器 DNS 设置：

```bash
echo "nameserver 8.8.8.8" >> /etc/resolv.conf
systemctl restart emergency-decision
```

### Q5: 手机端侧边栏打不开

**原因**：浏览器缓存了旧的 JS 文件。

**解决**：手机浏览器清除缓存后重新访问，或加 `?v=2` 参数：`http://IP?v=2`

### Q6: 502 Bad Gateway

```bash
# Flask应用崩溃了，检查日志
journalctl -u emergency-decision -n 50 --no-pager

# 重启
systemctl restart emergency-decision
```

### Q7: 上传场景失败（413 Request Entity Too Large）

**原因**：Nginx 上传大小限制。

**解决**：已在 nginx.conf 中设置为 20M，如仍不够：

```bash
nano /etc/nginx/sites-available/emergency-decision
# 修改 client_max_body_size 50M;
systemctl restart nginx
```
